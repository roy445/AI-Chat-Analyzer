# Brand assets

The local SVG assets are bundled for stable rendering and are used only as platform identifiers in the import flow.

- LINE: https://www.line.me/en/logo
- Instagram: https://www.meta.com/brand/resources/instagram/instagram-brand/
- Messenger: https://www.meta.com/brand/resources/facebook/messenger-icon/

The platform marks remain unmodified inside their own colored containers. Please review each platform's current brand guidelines before using them in paid advertising, printed material, or a product that implies partnership or endorsement.
