# AI Chat Analyzer 錯誤代碼手冊

本手冊定義網站可能回傳的錯誤代碼、使用者影響、建議動作與服務停止條件。錯誤代碼會顯示在使用者畫面，回報表單可直接帶入代碼。

## 嚴重度

| 等級 | 定義 | 使用者體驗 | 服務策略 |
|---|---|---|---|
| S0 | 致命安全或資料完整性風險 | 可能造成資料外洩、錯誤儲存或全站無法使用 | 立即停止受影響服務，寄送通知給維護者，顯示大型公告 |
| S1 | 高度影響主要流程 | AI、分享或解析大範圍失效 | 暫停受影響服務，顯示大型公告並建議回報 |
| S2 | 單次操作失敗 | 目前操作無法完成，但本機功能仍可繼續 | 保留其他功能，顯示代碼與回報入口 |
| S3 | 非阻斷性問題 | 部分資料缺少或顯示不完整 | 提示使用者檢查檔案或稍後重試 |
| S4 | 訊息或格式提醒 | 不影響核心流程 | 僅顯示提示 |

### 基本本機分析（ANALYSIS）

基本分析是在瀏覽器本機整理與計算聊天資料，**不需要 AI provider**。它與使用者之後主動點擊的 AI 深度分析完全分開。

| Code | 等級 | 說明 |
|---|---:|---|
| ANALYSIS-001 | S1 | 基本分析服務被管理員暫停。 |
| ANALYSIS-002 | S2 | 基本分析資料不足，無法產生可靠的客觀統計。 |
| ANALYSIS-003 | S2 | 本機統計或指標計算失敗。 |
| ANALYSIS-004 | S2 | 聊天資料結構無法對應本機分析器。 |
| ANALYSIS-005 | S3 | 本機分析被重新整理、離開頁面或瀏覽器中斷。 |
| ANALYSIS-006 | S0 | 發現本機資料處理可能混用其他使用者資料，應立即停止分析服務。 |

### AI 深度分析與 AI 問答（AI）

AI 功能只有在使用者主動點擊「AI 深度分析」或送出 AI 問答後才會啟動。關閉 AI 服務不會影響已完成的基本本機分析。

| Code | 等級 | 說明 |
|---|---:|---|
| AI-001 | S1 | AI 深度分析服務被管理員暫停；基本本機分析仍可使用。 |
| AI-002 | S1 | Gemini 或 OpenRouter 金鑰無效、過期或權限不足。 |
| AI-003 | S1 | 設定的 AI 模型不存在或目前不可用。 |
| AI-004 | S1 | AI provider 設定不完整或沒有可用的 provider。 |
| AI-005 | S2 | AI provider 受到速率或用量限制。 |
| AI-006 | S1 | AI 深度分析無法完成。 |
| AI-007 | S2 | AI provider 請求格式不相容。 |
| AI-008 | S2 | 使用者尚未完成基本分析，沒有足夠資料供 AI 深度分析。 |
| AI-009 | S1 | AI 問答服務被管理員暫停；基本分析與報告仍可使用。 |
| AI-010 | S1 | Gemini 與 OpenRouter 備援皆失敗，暫停受影響的 AI 操作並顯示公告。 |
| AI-011 | S0 | AI 回應疑似包含秘密或不應公開的敏感設定，應立即停止 AI 服務。 |
| AI-012 | S2 | AI provider 在期限內沒有完成深度分析回應。 |

## 顯示與處置規則

所有錯誤都應顯示：「抱歉，遇到了一些錯誤。錯誤代碼：`XXX`。如果方便的話，請點擊『回報錯誤』，幫助建立者知道如何改善。」

S0 與 S1 錯誤不可把 API key、資料庫 URL、完整 stack trace 或原始聊天內容送到瀏覽器。S0 錯誤應停止受影響服務並寄信給 `r03259468@gmail.com`；S1 錯誤應停止受影響功能，並在頁面顯示大型公告。S2–S4 僅影響目前操作，不應讓整個網站停止。

## 回報內容

回報郵件應包含錯誤代碼、發生時間、目前頁面、瀏覽器摘要、使用者自行填寫的問題描述，以及可選的聯絡信箱。不得自動附加原始聊天檔案、完整聊天內容、API key 或資料庫連線字串。
